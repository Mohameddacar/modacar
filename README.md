# modacar — Mohamed Dacar's Portfolio

Modern, high-performance personal portfolio website built with Next.js (App Router), TypeScript, and Tailwind CSS.

## 🚀 Features
- **Modern Design**: Premium dark aesthetic with glassmorphic accents, fluid typography, and responsive layouts
- **Interactive Showcase**: Dynamic project presentations, detailed case studies, and live links
- **Experience Timeline**: Professional journey, education, and technical background
- **Contact & Connect**: Direct contact form and social links

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## 🏃 Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
